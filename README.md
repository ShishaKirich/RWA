# RWA — маршрутизация и назначение длин волн

Решение задачи **RWA (Routing and Wavelength Assignment)** — классической задачи
оптимизации в оптических сетях связи: для набора запросов «источник → приёмник»
нужно проложить маршруты в ориентированном графе и назначить каждому длину волны
так, чтобы на одном ребре одна длина волны не использовалась двумя маршрутами
одновременно.

## Подход

Многоуровневая («сбалансированная») стратегия, обрабатывающая запросы по
нарастанию сложности:

1. `process_immediate_requests` — тривиальные и очень короткие запросы
2. `process_short_requests` — короткие пути
3. `process_medium_requests` — запросы средней сложности
4. `process_challenging_requests` — сложные запросы

Каждому маршруту подбирается свободная на всех его рёбрах длина волны
(`find_available_wavelength`), что исключает коллизии.

## Технологии

`Python` (стандартная библиотека: `collections`, `typing`)

## Запуск

```bash
python solution_rwa.py
```

Входные данные читаются из файлов:

```python
from solution_rwa import solve
result = solve("graph.txt", "requests.txt")
```

- `graph.txt` — первая строка: число вершин и рёбер; далее рёбра `u v`
- `requests.txt` — число длин волн, число запросов, затем пары `src dst`

## Структура

```
solution_rwa.py   — чтение входных данных и стратегия назначения длин волн
```
